# rbx-shop

Subcommand: declaratively manage Roblox game passes, badges, and developer products from `rbxshop.toml`. Typed Luau codegen with runtime env dispatch via `game.GameId`, regenerable offline with `rbx shop codegen` and verifiable with `--check`.

Part of [`rbx-forge/rbx-deploy`](https://github.com/rbx-forge/rbx-deploy). Not published as a standalone crate.
