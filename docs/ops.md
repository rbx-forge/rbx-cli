# Live operations

The commands that act on a running game are now their own tool, [rbx-ops](https://rbx-forge.github.io/rbx-ops/): `servers`, `analytics`, `ban`, `group`, `restart`, `data`, `memorystore`, `message`, `secret`, `ads` and `user`. Their documentation, and the safety model they share, live there.

`rbx` 0.12 still carries it, with the same flags, and the next release removes it.
